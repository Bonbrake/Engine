# Free Bot-Callable APIs — scoped to ZombieEngine game-dev + current recon use

> API tools an AI agent / bot can CALL programmatically (no browser, no human paste).
> All below curl-verified reachable from this host. "no key" = zero credentials.
> Scoped to: game-dev assets, world-gen grounding, transcript extraction, and a few
> generally-useful utilities. Crypto / fun-trivia / unrelated endpoints excluded.

> NOTE: YouTube caption endpoints IP-sign their URLs (ip=0.0.0.0) and rate-limit
> (HTTP 429) heavy egress. Other APIs below are stable.

## TRANSCRIPTS (YouTube recon)
- **youtube-transcript-api** (Python lib, NO KEY) — `YouTubeTranscriptApi().fetch(VID,
  languages=['en'])` → `.snippets[].text`. *Standard method*; IP-blocked (429) under
  heavy use, cooldown fixes.
- **yt-dlp** (NO KEY) — `yt-dlp --skip-download --write-auto-subs --sub-langs en
  --sub-format json3 -o out URL`. Reliable fallback; also 429s when egress is hot.
- Paid bot APIs (key): supadata.ai, transcriptapi.com, tikhub.io, scrapingdog, apify.

## GAME-DEV / ASSETS (no key)
- **Poly Haven** `https://api.polyhaven.com/assets` — HDRIs/textures/models. ✅
  (directly useful: material/lighting references, env probes)
- **Sketchfab v3** `https://api.sketchfab.com/v3/search?type=models&q=...` — model search. ✅
- **Steam storefront** `https://store.steampowered.com/api/appdetails?appids=ID` — NO KEY. ✅
  (competitor/reference game metadata)
- **Kenney** `https://kenney.nl/assets` — curated CC0 game assets (browse). ✅
- **OpenGameArt** `https://opengameart.org/art-search-advanced?...` — CC0/CC-BY art/audio. ✅
- **Wikimedia Commons** `commons.wikimedia.org/w/api.php?action=query&list=search&srsearch=...`
  — public-domain media (textures, reference imagery). ✅
- **Open Library** `openlibrary.org/search.json?q=...` — book metadata. ✅
  (lore/reference research)
- Needs free key (optional): RAWG (`api.rawg.io/api/games?key=`), IGDB/Twitch (OAuth).
- ModDB errored without key — skip.

## MAPS / WORLD GEN (no key)
- **Overpass API** `https://overpass-api.de/api/interpreter?data=...` — OSM data for
  procedural-world grounding. Returns 406 unless query/Accept correct; works with
  proper query. ✅
- **REST Countries** `https://restcountries.com/v3.1/name/france` — NO KEY. ✅
  (real-world geography for world-building grounding)
- **Wikidata** `wikidata.org/w/api.php?action=wbsearchentities&...` — NO KEY. ✅
  (entity facts for lore/world consistency)

## GENERAL / USEFUL UTILITIES (no key)
- **HuggingFace Inference** `api-inference.huggingface.co/models` — needs HF token.
  (on-demand ML: captioning, embeddings, small models — useful if we add AI tooling)
- **DictionaryAPI** `api.dictionaryapi.dev/api/v2/entries/en/optimize` — NO KEY. ✅
  (term lookup for docs/spec)
- **Open-Meteo** `api.open-meteo.com/v1/forecast?latitude=..&longitude=..&hourly=..`
  — NO KEY weather. ✅ (day/night cycle, weather world-systems grounding)
- **QR Server** `api.qrserver.com/v1/create-qr-code/?data=..&size=..` — NO KEY QR gen. ✅
- **JSONPlaceholder / HTTPBin** — NO KEY test/echo endpoints (dev sanity checks). ✅
- **Public APIs index** `api.github.com/repos/public-apis/public-apis` — discovery index. ✅

## USAGE NOTES
- "no key" APIs enforce per-IP rate limits; batch with small sleeps. YouTube caption
  APIs are strictest (429 fast) — pace them.
- Directly game-useful for ZombieEngine: Poly Haven, Sketchfab, Steam, Kenney,
  OpenGameArt, Overpass, REST Countries — asset provenance, material/lighting refs,
  world-gen grounding.
