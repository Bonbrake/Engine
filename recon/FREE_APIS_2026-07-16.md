# Free Bot-Callable APIs (verified reachable 2026-07-16, curl from this host)

> Purpose: API tools an AI agent / bot can CALL programmatically (no browser, no
> human paste). All below were curl-verified reachable from this machine. Web
> research done via curl (Firecrawl/web tools are paid-blocked). "no key" = works
> with zero credentials; "free tier" = needs a free API key.
>
> NOTE: YouTube caption endpoints IP-sign their URLs (ip=0.0.0.0) and rate-limit
> (HTTP 429) heavy egress — see transcript section. Other APIs below are stable.

## TRANSCRIPTS (YouTube)
- **youtube-transcript-api** (Python lib, NO KEY) — `pip install youtube-transcript-api`,
  `YouTubeTranscriptApi().fetch(VID, languages=['en'])` → `.snippets[].text`.
  *Standard method.* Intermittently IP-blocked (429) under heavy use; cooldown fixes.
- **yt-dlp** (NO KEY) — `yt-dlp --skip-download --write-auto-subs --sub-langs en
  --sub-format json3 -o out URL`. Reliable fallback; also 429s when egress is hot.
- Paid bot APIs (need key): supadata.ai, transcriptapi.com, tikhub.io, scrapingdog, apify.

## USAGE NOTES
- Most "no key" APIs are fine for agent use but enforce per-IP rate limits. Batch with
  small sleeps. YouTube caption APIs are the strictest (429 fast) — pace them.

  directly game-useful ones (asset provenance, material references, world-gen grounding).
