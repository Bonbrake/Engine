## M8.6 — Biome graph, palette constraints, and procedural asset grammar

> **M8.6 authoring plan.** Replaces 28 placeholder blocks with authored biome classification, palette transition rules, vegetation grammar, and settlement-surface asset rules.

### Cluster A: Biome Classification and Transitions

#### [M8.6-EXT-01] Whittaker Biome Classification
**tags:** biome, climate
**ctx:** Classify cell into Whittaker biome from temperature and precipitation.
**math:** `biomeIndex = argmin_{biome} distance((temperature, precipitation), biome.anchor)`.
**algorithm:** Author biome anchors as table; classify chunk cells; store biome ID in cell metadata.
**player-facing impact:** Forests, plains, tundra, and desert read naturally from climate alone.

#### [M8.6-EXT-02] Biome Blend Band at Boundaries
**tags:** biome, seamless
**ctx:** Two biome cells don’t snap; blend over 2-3 chunk width.
**math:** `blendFactor = clamp((distanceFromCenter - innerRadius) / (outerRadius - innerRadius), 0, 1)`.
**algorithm:** Sample biome palette by blended weights; interpolation is linear for vegetation density, smoothstep for color.
**player-facing impact:** Cross biome border without sudden texture swap.

#### [M8.6-EXT-03] Authored Palette Budget per Biome
**tags:** biome, palette
**ctx:** Each biome keeps a tight typed palette: ground material, vegetation set, rock set, prop set.
**math:** `paletteSize[biome] <= 4` for ground materials, `<= 3` vegetation sets, `<= 2` rock sets.
**algorithm:** Palette is authored once; world generator samples from palette with seeded variation.
**player-facing impact:** Visual variety without authored asset explosion.

#### [M8.6-EXT-04] Seasonal Palette Swap Table
**tags:** biome, season
**ctx:** Seasonal state shifts palette weights and vegetation density.
**math:** `seasonWeight = sin(2π * dayOfYear / 365)`; `density = baseDensity * (1 + seasonAmplitude * seasonWeight)`.
**algorithm:** Author seasonal delta tables; blend between summer/winter palette weights by day-of-year.
**player-facing impact:** World feels alive across sessions; visual progression without new assets.

### Cluster B: Vegetation and Settlement Asset Grammar

#### [M8.6-EXT-11] Space-Colonization Canopy Seed Solver
**tags:** vegetation, canopy
**ctx:** Distribute tree attractor points and grow canopy meshes toward light sources.
**math:** `F_total = Σ (direction / distance^2)` from light sources; branch grows along F_total; kill branches below light threshold.
**algorithm:** Unlike L-systems, vegetation explicitly competes for light; author trunk/branch grammar; runtime solves for final branch topology.
**player-facing impact:** Forest canopy reads as real canopy rather than uniformly spaced billboards.

#### [M8.6-EXT-12] L-System Mesh Generation with Impostor Fallback
**tags:** vegetation, lod
**ctx:** Generate tree/bush meshes from L-system rules at runtime; far instances use impostor quads.
**math:** L-system rewrite count per detailLevel; impostor distance threshold `d_impostor = baseDistance * (1 + windStrength * 0.2)`.
**algorithm:** Author rule set once; runtime expands per instance; wind field modulates terminal branch rotation.
**player-facing impact:** Forests dense enough to obscure vision without n³ authored-tree cost.

#### [M8.6-EXT-13] Vegetation Wind Disturbance Propagation
**tags:** vegetation, wind
**ctx:** Top-down wind disturbance texture affects vegetation instances; player/zombie traversal writes disturbance.
**math:** `disturbance(x,t) = windBase + inputForce(x,t-1) * decay`; per-vertex sway = `sin(phase + disturbance(x,t) * frequency) * amplitude`.
**algorithm:** Render-to-texture disturbance map at reduced resolution; sample per-vertex in VS or compute shader.
**player-facing impact:** Player running through grass leaves visible wake; zombie horde exhumes vegetation trail.

#### [M8.6-EXT-14] Settlement Surface Asset Rule Table
**tags:** settlement, grammar
**context:** Buildings place props, debris, and furniture from authored rule sets keyed by room type and damage state.
**math:** `ruleWeight = baseWeight * damageMultiplier * factionStyleBias`.
**algorithm:** Author grammar rules per room type: kitchen, bedroom, bathroom, garage; each rule specifies allowed props with weights.
**player-facing impact:** Entering a building reads as lived-in without authored interior layouts.

#### [M8.6-EXT-15] Road-Surface and Pavement Grammar
**tags:** settlement, road
**ctx:** Road segments place authored props from surface-material grammar sets: cracks, manhole covers, debris fields.
**algorithm:** Macro-graph surface type cache feeds grammar solver; author 4 pavement/4 dirt rule sets.
**player-facing impact:** Roads feel consistent across chunks; no jarring surface swaps.

#### [M8.6-EXT-16] Decal Atlas Runtime Projection
**tags:** decal, runtime
**ctx:** Runtime atlas packs authored decals for blood, bullets, cracks, graffiti.
**math:** `atlasUV = baseUV + (decalType * atlasTileSize) + (variant * atlasTileSize * typeCount)`.
**algorithm:** Pool decal projection handles; limit active count; prioritize recent damage near camera.
**player-facing impact:** Battle damage reads on surfaces without per-decal authored textures.

#### [M8.6-EXT-17] Procedural Signage Grammar
**tags:** signage, grammar
**ctx:** Context-free grammar generates road signs, shop signs, hazard labels with seeded text + icon selection.
**math:** `signText = grammar.expand(startSymbol, seed)`; same seed yields same text.
**algorithm:** Author replacement tables for word+icon pairs; grammar assembles 1-3 word signs; instance text projected onto authored sign mesh.
**player-facing impact:** World reads as coherent civilization without authored sign textures.

### Cluster C: Weather and Atmosphere Integration

#### [M8.6-EXT-21] Authored Weather Profile Table
**tags:** weather, atmosphere
**ctx:** Define weather states from authored parameter profiles: cloud density, precipitation rate, wind vector, acoustic muffling, zombie sight penalty.
**math:** `zombieSightRange = baseSightRange * (1 - precipitation * 0.4) * (1 - fogDensity * 0.6)`.
**algorithm:** Author 6-8 profiles; director schedules transitions with authored hysteresis to avoid flapping.
**player-facing impact:** Rain muffles audio, reduces zombie detection, rustles foliage; clear nights carry silent risk.

#### [M8.6-EXT-22] Acoustic Muffling by Precipitation and Terrain Cover
**tags:** weather, audio
**ctx:** Weather state modifies M6 audio propagation parameters.
**math:** `absorption += precipitation * rainAbsorption; muffling += canopyDensity * foliageMuffle`.
**algorithm:** Update material-indexed absorption table per weather state; M6 portal/voxel system reads updated values automatically.
**player-facing impact:** Gunshots sound different in rain vs. clear; forests muffle; open fields carry.

#### [M8.6-EXT-23] Temperature/Humidity Grid for Survival Integration
**tags:** weather, survival
**ctx:** Spatially varying temperature and humidity fields feed M0 survival systems.
**math:** `airTemp = biomeBaseTemp + diurnalCycle + weatherFrontDelta + elevationLapse * altitude`.
**algorithm:** Grid resolution 1 per chunk; sample with bilinear filter; cache per-chunk.
**player-facing impact:** High altitude → colder; rain → wetness; wind chill modifies effective temperature.

#### [M8.6-EXT-24] Authored Biome Transition Hazard Table
**tags:** biome, hazard
**ctx:** Crossing biome boundaries triggers authored hazard sets: quicksand in marsh, thin ice in tundra, flash flood in desert wadis after rain, poison ivy in forest edges.
**math:** `hazardProbability = transitionBias * weatherAmplifier`.
**algorithm:** Author hazard per biome pair; spawn only within 1 chunk of boundary; duration tied to weather state.
**player-facing impact:** Biome travel carries risk/reward; crossing requires preparation.

#### [M8.6-EXT-25] Authored Wildlife Density by Biome
**tags:** biome, ecology
**ctx:** Author density curves for deer, rabbit, bird by biome and season.
**math:** `spawnWeight = baseDensity * seasonFactor * weatherFactor * playerNoiseFactor`.
**algorithm:** Decoupled spawn density from authored curves; runtime samples with player-noise rejection near camps.
**player-facing impact:** Forests have deer; tundra have scarce prey; night reduces visibility and changes species.

#### [M8.6-EXT-26] Settlement Style by Biome Culture
**tags:** settlement, culture
**ctx:** Three authored culture styles: suburban, rural, industrial; each maps to biome palette and grammar.
**math:** `styleScore = cultureWeight[biome] * roadDensity + settlementDensity`.
**algorithm:** Author grammar variants per style; runtime selects dominant style by local density.
**player-facing impact:** Suburban sprawl, rural farmsteads, and industrial rail yards read as regional cultures.

#### [M8.6-EXT-27] Biome Audio Palette + Wind Layer
**tags:** biome, audio
**ctx:** Each biome has authored ambient audio palette: wind, insects, birds, distant threats.
**algorithm:** Author 3-layer palette per biome: base ambience, conditional layer, threat-reactive layer; M6 voice/audio director mixes.
**player-facing impact:** Audio reads biome and threat state: forest birds cut out when horde approaches; wind rises before storm.

#### [M8.6-EXT-28] Authoring Budget and Asset Count Validation
**tags:** authoring, quality
**ctx:** Hard cap on authored biome assets and validate at build/load time.
**math:** `totalAuthoredAssets = Σ across biomes; assert(totalAuthoredAssets <= authoredAssetBudget)`.
**algorithm:** CI/repo script counts authored assets; fail build if budget exceeded.
**player-facing impact:** N/A; prevents authored-asset creep from breaking minimal-asset mandate.
