## M5.4 — AI director, spatial mission grammar, and event pacing

> **M5.4 authoring plan.** Replaces 17 placeholder blocks with executed systems: spatial conflict detection, personality-weighted event selection, settlement-pressure grammar, and voice-directed emergency broadcasts.

### Cluster A: Director Core

#### [M5.4-EXT-01] Director State Machine
**tags:** director, pacing
**ctx:** Director operates in states: calm, tension, chase, recovery, siege. Transitions fire on player-action thresholds and world-state triggers.
**math:** `stateScore[calm] += dt * calmWeight; stateScore[tension] += noiseEvents * tensionWeight; maxScore → nextState`.
**algorithm:** Every 30s, evaluate state weights; transition if delta exceeds hysteresis margin to avoid flapping.
**player-facing impact:** Pacing feels authored: quiet scavenging → sudden horde → recovery → bigger threat.

#### [M5.4-EXT-02] Personality Preset Pools
**tags:** director, variety
**ctx:** Three personality presets produce materially different pacing curves: Cassandra escalates, Phoebe calms then bursts, Randy throws chaos.
**math:** `escalationRate[Cassandra] = 1.4; calmBias[Phoebe] = 0.6; entropy[Randy] = 0.9`.
**algorithm:** Each preset biases stateScore weights and event selection by reroll count; same seed yields same run.
**player-facing impact:** Director feels like a personality, not a random number table; replays stay varied but consistent.

#### [M5.4-EXT-03] Spatial Conflict Detector
**tags:** director, spatial
**ctx:** Detect open-field vs. building vs. choke-point contexts from navmesh/cell data.
**algorithm:** Analyze player cell + adjacent cells for `coverDensity`, `lineOfSightCount`, `egressCount`; classify context vector.
**player-facing impact:** Open field → horde from tree line; building → breach event; choke → ambush from windows.

#### [M5.4-EXT-04] Event Grammar Slot Filler
**tags:** director, grammar
**ctx:** Events are templates with typed slots: faction, reward, risk, moralChoice. Slot filler reads current world state and writer constraints.
**math:** violationScore = Σ abs(constraint - worldState); valid if maxScore < threshold.
**algorithm:** For each event template, assign slot values from candidate pools; reject if world-state constraints fail; pick lowest-violation assignment.
**player-facing impact:** Events feel coherent: survivor asks for medicine only when settlement has wounded; horde attacks only when population is high.

### Cluster B: Voice-Directed Director Output

#### [M5.4-EXT-10] Director Radio/Voice Dispatch
**tags:** director, voice, audio
**ctx:** Instead of text popups, director delivers narrative events through voice-directed radio or survivor whispers.
**algorithm:** Map event intent → voice intent table; M6 voice director renders with distance, occlusion, material diffraction; use minimal authored lines.
**player-facing impact:** Tension comes from hearing an unfamiliar survivor whisper from a locked room, not reading a quest marker.

#### [M5.4-EXT-11] Settlement Pressure Budget
**tags:** director, settlement
**ctx:** Director budgets global settlement pressure based on population, facilities, and resource surplus.
**math:** `pressureBudget = basePressure + α * population + β * facilityCount - γ * surplusFood`.
**algorithm:** If pressureBudget exceeds threshold, spawn settlement crisis event; scale event severity with overflow.
**player-facing impact:** Stay lean to stay safe; grow fat and attract siege.

#### [M5.4-EXT-12] Moral Consequence Propagation
**tags:** director, narrative
**ctx:** Moral choices update reputation graph and future event eligibility.
**math:** `rep[A] += Δ; rep[B] -= k * Δ; exclusiveAccess[A] = rep[A] > τ`.
**algorithm:** After choice, propagate deltas; gate future event slots on current rep state.
**player-facing impact:** Choices echo. Save faction A → faction B refuses trade; survivorship bias becomes story.

#### [M5.4-EXT-13] Horde Trigger by Wealth + Noise + Time-of-Day
**tags:** director, survival
**ctx:** Horde events scale with settlement wealth, recent noise footprint, and darkness.
**math:** `hordeScore = wealthFactor * Σ(value) + noiseFootprint * 1.2 + nightBias`.
**algorithm:** Compare hordeScore against escalating thresholds; if exceeded, schedule horde with lead time suitable to environment.
**player-facing impact:** Silent nights still carry risk; noisy survivors get punished.

#### [M5.4-EXT-14] Director Debug Overlay
**tags:** director, debug
**ctx:** Minimal ImGui overlay exposes director state, event queue, slot fills, and stateScore weights for iteration.
**algorithm:** Only active in dev/debug builds; no runtime cost in shipping.
**player-facing impact:** N/A; authoring/tuning tool only.

#### [M5.4-EXT-15] Deterministic Director Replay Integration
**tags:** director, replay
**ctx:** Director events are deterministic given seed + input history.
**algorithm:** Hash `{ seed, eventQueueHead, worldStateSnapshot }` each event spawn; validate on replay by comparing hash stream.
**player-facing impact:** replays/ghosts stay consistent across runs.

#### [M5.4-EXT-16] Event Cooldown + Proximity Filter
**tags:** director, performance
**ctx:** Bad events do not spawn inside soft/hard cooldowns or within minimum player distance.
**math:** `cooldownRemaining = max(cooldownMin, eventDuration * cooldownScale)`; `proximityBlocked = distanceToLastSpawn < minSeparation`.
**algorithm:** Reject candidate events violating cooldown or proximity filters; fallback to safe ambient event.
**player-facing impact:** No impossible back-to-back sieges; events breathe.

#### [M5.4-EXT-17] Authoring Tooling: Event Template Schema
**tags:** director, tooling
**ctx:** Define event template as JSON-ish schema: id, tags, slotConstraints, weight, cooldown, exclusivityTags.
**algorithm:** Validate template at load time; reject if no valid slot filling exists for current world state.
**player-facing impact:** New authored events require no engine build; modders add content via data file.
