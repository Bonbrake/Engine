### ADDITION 2: SEAMLESS INTERIORS (No Loading Screens)

**Extends:** M2.6 streaming, M4 chunk streaming, M8.6 settlements

**Best-in-Class References:**
- **UE5 World Partition:** Automatic grid partitioning, cell streaming by camera distance, Data Layers for conditional loading, HLOD for distant cells
- **Gothic 1/2:** Seamless interior/exterior — no loading screens, unified world space
- **RDR2:** Portal-based occlusion, streaming priority by gameplay relevance
- **Starfield (Creation Engine 2):** Criticized FOR loading screens — we do the opposite

**Our Implementation:**

| Feature | Implementation |
|---------|----------------|
| **Unified World Partition** | Exterior cells (64m) + Interior cells (variable) in SAME coordinate space; both streamed via single priority queue |
| **Door Transition** | On approach (5m): async preload interior cell (geometry + navmesh + entities) → camera warp + cell priority boost (<200ms, **no fade/load screen**) |
| **Shared Navmesh Tiles** | Off-mesh links at door thresholds (Recast/Detour); agents path interior↔exterior seamlessly |
| **Data Layers (UE5 Pattern)** | Quest phase / time-of-day / faction control swap cell content without reload — `CellDataLayer { condition, entityDelta[] }` |
| **Interior Culling** | Portal-based occlusion (door frames = portals); GPU-driven culling via M4.5 bindless |
| **Streaming Priority** | `score = w_dist·dist + w_vel·velPred + w_quest·questRelevance + w_threat·threatLevel` |
