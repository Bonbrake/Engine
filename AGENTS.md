# ZombieEngine AGENTS.md

This file provides context for AI agents working on the ZombieEngine project.

## Project Overview
Zombie Engine is an M-rated zombie survival game being developed with C++, Vulkan, SDL3, and Jolt Physics.

## Key Directories
- `/src` - Main source code
- `/spec` - Game design specification (READ-ONLY)
- `/build` - Build output (gitignored)
- `/scripts` - Build and utility scripts

## Current Focus

- Skill development for game development workflows
