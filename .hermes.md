# ZombieEngine — Hermes Project Rules

## Project
ZombieEngine is an M-rated zombie survival game. C++ / Vulkan 1.4 / SDL3 / Jolt Physics 5.6. Built with VS 2022 + CMake + Ninja + vcpkg + enkiTS. Target: RTX 2000-series, 6GB VRAM, 30 FPS floor. Dev target: RTX 2070 SUPER, 60 FPS.

## Key Directories
- `/src` — Main source code
- `/spec` — Game design specification (READ-ONLY unless explicit edit approval)
- `/build` — Build output (gitignored)
- `/scripts` — Build and utility scripts
- `/docs` — Reference and research
- `/assets` — Game assets

## Spec Layout
Spec files at `spec/` — M0 through M13 plus M4.5 and M6.5. Each .md file + .index.json sidecar. APPENDICES.md is a block-ID index, not duplicate definitions. 812 verified EXT IDs total. Files are READ-ONLY unless explicitly approved.

## Workflow
- Bug hunting: read current state, reproduce symptom, form ONE hypothesis, verify against output, patch, re-verify. Three clean passes before declaring done.
- Spec work: propose EXT blocks in plan-fleshing mode. Fact-check duplicates against ALL spec files including APPENDICES.md and every .index.json. Use `grep -r` across spec/ globally before assigning new IDs.
- Build: `scripts/build_ze.cmd` with optional build-dir arg. Use `build-ninja/` for normal, `build-asan/` for sanitizer builds. `build/` is gitignored.
- Git: push to `origin spec/m0-parity-reformat`. Commit with `git add -u` to avoid scooping stray session folders. Offer PRs, don't auto-merge. Keep build healthy and deps updated weekly.

## Minigame Design
Interactions must IMPROVE on zombie-survival peers (SoD2, DL2, PZ, 7DTD). No direct copies. Welding = steady-bead minigame. Hotwire = tone-based (NoPixel style). Lockpick = harder than Fallout — over-lift drops all pins, material tiers, noise alerts. Hacking = computer-based intrusion inspired by Watch Dogs / Deus Ex / Cyberpunk, NOT Fallout terminal hack.

## Build & Hardware
Windows 11 Insider. Vulkan validation layers active. Afterburner + RTSS hooking requires STORAGE_BIT workaround. Local coder at http://localhost:8080 (Qwen3-Coder-30B). No daemons, no startup entries. All helper scripts dormant when parent app is closed.
