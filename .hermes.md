# ZombieEngine — Hermes Project & Workflow Guidelines

## 1. Project Context & Hardware Target
ZombieEngine is an M-rated, 100%-procedural zombie survival game built on a custom **C++ / Vulkan 1.4** architecture.
- **Compiler / Toolchain:** MSVC v14.44 (Visual Studio 2022) + CMake + Ninja + vcpkg + enkiTS.
- **Target Hardware Floor (Tier-0):** RTX 2070 SUPER / 6GB VRAM, 30 FPS floor @ 1080p HDR.
- **Local AI & SLM Integration:** Embedded `llama.cpp` C++ API (`libllama.a` / `llama.dll`) running lightweight GGUF models (Qwen-2.5-3B-Q4_K_M) consuming <2GB VRAM. Zero external daemons or Python servers required.

## 2. Master Blueprint Primacy & Spec Layout
- **Master Blueprint:** [`recon/plans/FINAL_COMPREHENSIVE_PLAN.md`](recon/plans/FINAL_COMPREHENSIVE_PLAN.md) — **The live source of truth.** All subagents and developers MUST read this plan first.
- **Spec Working Set (`spec/`):** 33 milestone files (M0 through M13, M4.5, M6.5).
- **Verified EXT Blocks:** **1,031 mathematically verified EXT logic blocks** backed by 100 primary-source verified research papers (`[S]`).
- **Index Sidecars:** Every `.md` file has a corresponding `.index.json` sidecar. Run mechanical verification scripts after any change.

## 3. AAA Workflow & Bug Hunting Methodology
- **Bug Hunting:** Read current state -> reproduce symptom -> form **ONE** hypothesis based strictly on error tracebacks -> patch -> verify. Three clean passes required before declaring a task resolved.
- **Spec Modification Protocol:** Milestone spec files are READ-ONLY unless explicit plan approval is granted. Fact-check duplicates across all 33 spec files and `.index.json` sidecars before proposing new IDs.
- **Build Commands:** Execute `scripts/build_ze.cmd`. Use `build-ninja/` for normal builds, `build-asan/` for AddressSanitizer builds.
- **Git Branching:** Target branch is **`main`**. Commit verified changes cleanly to `main`.

## 4. Quality Assurance & Verification Gates
1. **Mechanical Parity:** Run `python scripts/verify_m0_parity.py` and `python scripts/verify_ext_block_counts.py`. Block counts and sidecars MUST match with zero warnings.
2. **Sanitizer Gate:** C++ code modifications must compile and run clean under AddressSanitizer (`build-asan/`) with zero memory leaks, dangling pointers, or buffer overflows.
3. **Automated Unit Testing:** Run `build/tests/ZombieEngineTests.exe`. 100% of Catch2 unit tests must pass cleanly.

## 5. Hardware Guardrails & 6GB VRAM Allocation Ledger
Allocations are hard-partitioned via Vulkan Memory Allocator (`vmaCreatePool`) caps:
- **Render Targets & G-Buffer:** 1,200 MB (Fixed Pool)
- **Meshlet & Index Buffers:** 600 MB (Cluster LOD Eviction)
- **Texture Streaming Pool:** 2,200 MB (RVT Mip Eviction)
- **Animation & Rigs:** 300 MB (Delta Compression)
- **Audio & Compute:** 200 MB (Compute Ray Cap)
- **Engine Reserve & OS Slack:** 1,500 MB (Triggers Emergency VMA Defragmentation `M0-EXT-102`)

## 6. Core Engine Innovations & Gameplay Mechanics
- **Relative-To-Eye (RTE) Floating Origin (`M0-EXT-101`):** `int64_t` world coordinates eliminating 32-bit float jitter at 100,000+ km.
- **IEEE 754 Determinism (`M2-EXT-101`):** `/fp:precise` and hardware register flushes enforcing bit-identical Jolt physics across PC/Console.
- **Vulkan Work Graphs (`M0-EXT-106`):** GPU-driven command generation via `VK_AMDX_shader_enqueue`.
- **Lock-Free Asset Hot-Reloading (`M0-EXT-105`):** IOCP directory watching for zero-restart shader and asset swapping.
- **Atomic Save WAL (`M7-EXT-101`):** Double-buffered Write-Ahead Logging preventing save corruption on power loss.
- **RVT Decal Splatter (`M4-EXT-103`):** Projects infinite persistent blood and bullet decals directly into Virtual Textures.
- **Topology-Aware Thread Affinity (`M1-EXT-101`):** Pins render/physics jobs to P-cores and background streaming to E-cores.
- **Sub-Tick Input Netcode (`M11-EXT-101` / `M12-EXT-101`):** Microsecond timestamped inputs with Zstd snapshot delta compression.
- **Minigames:** Welding (steady-bead), Hotwiring (tone-based), Lockpicking (multi-pin overlift), Hacking (Watch Dogs intrusion).
