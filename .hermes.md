# ZombieEngine — Hermes Agent Context (spec navigation bridge)

This file tells Hermes how to load the ZombieEngine design spec with minimal
context. The full spec is split into agent-readable files under `spec/`.

## Spec navigation (optimized)
1. Start at `spec/llms.txt` — canonical index (H1 + summary + per-milestone file list with EXT-block counts).
2. Read `spec/AGENTS.md` for the full file map and editing rules.
3. Open ONLY the one milestone file you need (e.g. `spec/M4.md`). Each `#### [ID]` block is self-contained (Systems Touched / Math / How It Works / Reference Implementation / Player-Facing Impact) with a `> **tl;dr**`, `> **tags**`, `> **meta**` (depends-on/depended-by) and `> **ctx**` line at the top, plus an HTML anchor `<a id="Mx-EXT-NN">` for deep-linking.
4. `spec/M0.index.json` (and sibling index files) give O(1) `id → {title, tags, tldr, depends_on, depended_by, line, anchor}` lookups — load instead of the .md when only metadata is needed.
5. Keep context lean: read the block you need, not the whole milestone, not the whole `spec/` corpus.

- The versioned spec (v73+) is single source of truth for every milestone.
- Specificity protocol: every number is authoritative; missing context = stop, don't invent.
